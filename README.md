Flip it on and the brightness slider runs past 100%, up to 160% on a Liquid Retina XDR or Pro Display XDR.

## Install

Requires macOS 15+, Xcode and [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```sh
make install
```

`make run` builds a debug copy instead, and `make test` runs the tests.
